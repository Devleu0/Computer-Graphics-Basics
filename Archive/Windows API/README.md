# Windows API 독립 자료

이 자료는 Win32를 이용한 Windows 데스크톱 프로그래밍을 다룹니다. NPR 셰이더 학습과 별개의 주제이므로 저장소의 권장 NPR 경로에는 포함되지 않으며, 기존 학습 문서와 예제를 보존하기 위해 이 위치에 둡니다.

- [Windows API 학습 커리큘럼](./Lessons/0.%20Win32%20학습%20커리큘럼.md) — 창·메시지, GDI·입력, 컨트롤·리소스, 파일·스레드
- [예제 테스트 환경 활용 가이드](./Lessons/Win%20API%20예제%20테스트%20환경%20활용%20가이드.md) — Visual Studio에서 예제 소스를 구성하고 실행하는 방법
- [예제 소스](./Examples/) — HelloWorld, Paint, Notepad, FileSearcher

예제별 세부 설명과 연결 파일은 커리큘럼 및 각 학습 문서에서 확인하세요.
