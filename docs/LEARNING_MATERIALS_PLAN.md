# 학습 자료 개선 계획

이 문서는 저장소의 학습 효용을 높이기 위한 작업 목록과 진행 기록입니다. 주차나 완료 기한은 두지 않으며, 문서와 예제를 실제로 확인한 뒤 상태를 갱신합니다.

## 개선 원칙

- 다음 단계는 저장소 안의 자료로 이어지거나, 아직 자료가 없으면 그 사실과 필요한 작업을 명확히 표시합니다.
- 시각 자료는 개념을 설명하는 다이어그램부터 추가합니다. 실제 실행 화면은 해당 환경에서 확인한 결과만 사용합니다.
- 코드 예제는 필요한 선수 코드, 실행 환경, 호스트 측 설정, 예상 결과를 함께 설명합니다. 일부 코드라면 발췌임을 표시합니다.
- 개념 목록은 왜 필요한지, 앞뒤 개념과 어떻게 연결되는지, 학습자가 직접 확인할 방법을 포함하도록 보완합니다.
- 문서를 보완할 때 상대 링크와 코드 검증 상태를 함께 확인합니다.

- [x] DirectX 11 커리큘럼에 초급·중급·고급 경로, 연결되는 실습 문서, 각 단계의 결과와 확인 기준을 추가했습니다.
