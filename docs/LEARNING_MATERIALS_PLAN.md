# NPR 중심 실행형 학습 프로젝트 개선 계획

## 방향

저장소의 대표 결과물을 **Unity URP에서 바로 실행해 볼 수 있는 NPR(툰) 셰이더 데모**로 정합니다. Unity 셰이더와 HLSL/그래픽스 자료는 그 결과물을 이해하고 확장하는 선수 경로로 안내하고, DirectX 11·Win32는 별도의 참고 학습 경로로 유지합니다. 문서 수를 늘리는 것보다 재현 가능한 실행, 측정 가능한 완료 기준, 검증 상태의 투명성을 우선합니다.

계획 수립 당시 Unity 2022.3.14f1 / URP 14.0.9 프로젝트에는 문서의 NPR 코드를 바로 실행할 씬이 없었습니다. 데모 자산과 씬은 추가했으며, 이제 고정된 프로젝트 버전에서의 셰이더 컴파일과 화면 검증이 남아 있습니다.

## 진행 원칙

- 각 단계는 사용자가 실제로 열고 실행할 수 있는 결과를 우선합니다. 스크린샷이나 컴파일 성공은 실제 검증한 경우에만 주장합니다.
- Unity 자산은 프로젝트의 기존 버전과 URP 설정에 맞추며, 생성 스크립트는 반복 실행해도 결과가 예측 가능해야 합니다.
- 문서의 완성형 코드와 프로젝트 내 실행 파일은 서로 동기화하고, 미검증 상태 및 필요한 에디터 버전을 기록합니다.
- NPR 핵심 경로의 실행·렌더 검증이 완료될 때까지 새 심화 주제보다 실행 안정성과 실습 재현성을 우선합니다.
- 이미 완료된 문서·도식·Win32 보강 작업은 아래 이전 작업 이력으로 보존하되, 이전 계획의 미완료 항목은 이번 NPR 방향의 필수 작업으로 간주하지 않습니다.
